# Etsy calculator: maintenance notes

The calculator lives in `etsycalc/` and is plain static files: no build step, no dependencies.

| File | Purpose |
| --- | --- |
| `etsycalc/calc.js` | Fee engine and the Etsy fee constants (`FEES`). Single source of truth. |
| `etsycalc/app.js` | Calculator page behaviour (form, results, price helper, compare, copy, CSV). |
| `etsycalc/site.js`, `config.js` | Analytics and consent-gated ads. Inert until IDs are set in `config.js`. |
| `etsycalc/*/index.html` | Guide and privacy pages, generated by `tools/etsycalc/build-pages.js`. |
| `etsycalc/tests/` | Tests (not deployed). |

## Everyday commands (run from the repo root)

```bash
node --test etsycalc/tests/calc.test.js etsycalc/tests/site.test.js   # all tests
node tools/etsycalc/build-pages.js                                    # regenerate guides after editing the generator or calc.js
```

## When Etsy changes a fee

1. Edit the value in `FEES` and `DEFAULTS` in `etsycalc/calc.js` (and `verified` / `verifiedLabel`).
2. Update the matching text and `value="..."` attributes in `etsycalc/index.html` (a test fails if they disagree).
3. Update the prose in `tools/etsycalc/build-pages.js`, then run the build and the tests.

Sources to re-check: Etsy Fees & Payments Policy, Etsy help "Regulatory Operating Fee", Etsy Payments Policy.

## Releasing without touching the rest of the site

`build-release.js` assembles a deploy folder equal to the live Netlify deploy plus the calculator only, and fails if any
other file would change. It needs the live file list (`netlify api listSiteFiles`).

```bash
node tools/etsycalc/build-release.js --out <empty dir> --manifest <live-manifest.json> --base <git ref of the live tree>
npx netlify-cli deploy --dir <out dir> --site <site id> --prod
```

Rollback: Netlify UI > Deploys > pick the previous deploy > "Publish deploy" (free, instant).
Never change DNS or the ImprovMX mail records when publishing.

## Analytics (Umami Cloud, enabled 2026-11-03)

Active on the calculator, guides and privacy page via `etsycalc/config.js` (website ID) and `etsycalc/site.js`.
The tracker never sends the URL hash or query string (shared links carry the entered numbers) and honours Do Not Track.
Events: `calculator_used`, `price_helper_used`, `compare_used`, `copy_summary`, `copy_link`, `export_csv`, `export_compare_csv`.
The privacy page text lives in `build-pages.js`; keep it in step with any tracker change.

## Google Search Console

The verification meta tag is stored in `tools/etsycalc/google-site-verification.html` and added to the homepage `<head>` by
`build-release.js` (the release builder proves the homepage differs from live by that one line only).
Keep it in place, because Google re-checks it.

## Turning on AdSense

1. Apply at adsense.google.com for the domain `raskyjack.com` (Google reviews the whole domain, not only `/etsycalc/`).
2. After approval, create ad units and put the publisher ID and unit IDs in `etsycalc/config.js`.
3. In AdSense > Privacy & messaging, enable Google's certified consent message for the UK/EEA (Google requires a certified CMP
   for UK and EEA visitors). Until then the built-in accept/reject banner gates all ad scripts.
4. Add `ads.txt` at the site root (`raskyjack.com/ads.txt`) with the line Google gives you, for example
   `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`.
5. Update the Advertising paragraph in the privacy page generator, rebuild, release.
