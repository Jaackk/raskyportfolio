Prototype

SportsPredict

A tennis prediction and analytics prototype: match predictions with confidence levels, player form and model performance, laid out so you can actually read them.

Interface mock-up of the TennisPredict dashboard.

What it is

I like sport and I like data. SportsPredict is where I'm learning how far you can get with form, context and simple models, and how to show the result without drowning people in numbers.

It's a prototype and a learning project. It doesn't promise winners.

  • Predictions

    Each match with a predicted winner and a confidence level.

  • Form & context

    Recent form and match context feeding each prediction.

  • Readable

    A clean dashboard that works on a phone.
