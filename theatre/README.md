## Architecture and lifecycle

- `chapters.js` owns scene order, durations, captions, asset URLs and destinations. Besides image/video alternatives it supports `manualImage`, `thirdImage`, arrays of actual `screens` and `graphics`, and timed `ambientVideos` with their posters and local start/end cues.
- `presentation.js` renders the compositions. It does not own the clock or global listeners. Playing-image treatments draw from the same decoded video.
- `theatre.js` owns lifecycle, timing, media synchronization, input takeover, focus, reduced motion, buffering and teardown.
- `sound.js` owns one decoded premix and at most one active Web Audio buffer source. Visual MP4s have no audio stream and are muted.
- `launch.js` attempts audio unlock inside the launch gesture before loading the controller. `invitation.css` styles the homepage invitation; the presentation CSS and media load after intent.

Pause freezes the sequence, video and soundtrack. Next/Back seek them together. Hidden tabs pause and require explicit resume. Audio-context interruption pauses an audio-clocked show; Resume attempts to unlock it again. Exit cancels animation/buffering timers, aborts scoped listeners and fetches, disconnects observation, releases videos and closes its context. Starting again uses the original homepage Theatre Mode launcher; no separate replay action remains.

The next primary clip is selectively warmed and reused; save-data mode skips warming. Peripheral B-roll begins loading one second before its cue. B-roll is omitted in manual/reduced-motion mode and on compact phones below 700 px viewport height at creation; other portrait layouts show a complete portrait beside the main performance. The earlier face-excluding detail crops are unused. At both the practice and main live-performance entrances, the clock and soundtrack wait for initial video data for up to eight seconds. Failure/timeout continues with the photograph. Later unavailable video can hold its last visible frame while the common edit advances. Missing images leave text. Fallbacks never establish that unavailable footage actually played.

Reduced motion uses static manually stepped scenes, no video or automatic visual movement, and sound off initially. Explicit Sound can play from the selected scene; manual chapter changes realign sound. Preference changes preserve focus on visible controls. Responsive compositions retain the skate action, playing hands, product panels and river composition. The same red-shirt practice take is used at every size; the earlier different-song portrait candidate is unused.
