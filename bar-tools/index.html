Working iOS app · development build

Made for a busy shift.

My bar and service app. Recipes, batch calculations, prep, stock and a little help finding the right wine, all close to hand on an iPhone.

View the source →Back to the portfolio

Real iPhone Simulator screens from the development build, using sample recipes and data.

The useful bits, together.

I wanted the small things that help a shift run well in one place: clear recipes, sensible batch quantities and a prep list you can actually work through.

It’s a native SwiftUI app with local storage. The working development build also includes stock and order lists, search and learning tools. It is not currently an App Store release.

  • On the phone

    Designed around quick reference and the jobs you do while getting ready for service.

  • Local and offline

    The core tools and saved work run on the device.

  • Built from experience

    A personal software project informed by the practical work of running a bar.
